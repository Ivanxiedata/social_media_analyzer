# Agent guide

This repo is a single agent skill: **social_media_analyzer**.

- Skill definition: [`skills/social_media_analyzer/SKILL.md`](skills/social_media_analyzer/SKILL.md)
- Tool it runs: `skills/social_media_analyzer/scripts/analyze-media` (also on `PATH` as `analyze-media` after `install.sh`)

Use it when the user shares a social media video link (Instagram / TikTok / YouTube) and wants the transcript, frames, caption/metadata, or a "why does this perform well" analysis. Follow the workflow in `SKILL.md`.
